متجر العربي - نسخة Firebase

الملفات:
- index.html: واجهة المتجر، تقرأ المنتجات والتقييمات من Firestore.
- admin.html: لوحة الإدارة، تضيف وتحذف المنتجات من Firestore.
- firebase-config.js: إعدادات Firebase الخاصة بتطبيق الويب.

مهم:
1) المشروع يستخدم Firestore مباشرة من المتصفح.
2) صور المنتجات يتم ضغطها وتحويلها إلى JPEG قبل حفظها داخل Firestore حتى لا تتجاوز حد حجم المستند.
3) قاعدة البيانات الحالية تم إنشاؤها في Test Mode أثناء التجهيز. يجب تغيير Rules لاحقًا وتأمين لوحة الإدارة باستخدام Firebase Authentication قبل الاستخدام الفعلي.
4) كلمة مرور لوحة الإدارة الحالية في هذه النسخة هي 123، وهي ليست حماية حقيقية لأنها موجودة داخل JavaScript. لا تعتمد عليها للإنتاج.
5) ارفع الملفات الأربعة معًا إلى GitHub Pages أو أي استضافة HTTPS.
